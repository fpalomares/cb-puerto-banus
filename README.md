# CB Puerto Banús

Static team website for the 2026-2027 season. No build or dependencies.

## Publish

Enable GitHub Pages from `main`, folder `/` in repository settings.

Expected address: https://fpalomares.github.io/cb-puerto-banus/

## Amazon links

After completing Amazon.es registration, edit `config.js` and set `amazonTag` to your tracking ID. Or set the individual `amazonLinks` to links generated by SiteStripe. The website switches to affiliate disclosures when tagged links are configured. Never add passwords or API credentials to these files.

## Season archive

19 Instagram posts, limited to the supplied 8 October 2026 announcement and newer posts. No earlier-season posts are included. Categories: Novedades, Agenda, Entrenamientos, Plantilla and Resultados. A mixed announcement can appear under more than one filter. Past event dates are labeled explicitly. Original downloaded image dimensions are recorded in posts.json.

Edit posts.json, then run node render-gallery.mjs from the project root to regenerate the gallery. No build step is required for hosting.
